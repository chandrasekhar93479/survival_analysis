# survival_analysis
# Titanic Dataset – Survival Analysis 📊

## 📌 Project Overview
This project focuses on analyzing the Titanic dataset to understand survival patterns based on passenger attributes such as gender, class, and age.

## 🎯 Objectives
- Clean and preprocess real-world data
- Analyze survival trends
- Visualize insights using Python libraries
- Answer business-driven questions with data

## 🧹 Data Cleaning
- Handled missing values in the Age column using median imputation
- Removed columns with excessive missing data (Cabin)

## 📊 Analysis Performed
- Survival comparison between males and females
- Impact of passenger class on survival
- Survival rate across different age groups

## 📈 Visualizations
- Bar chart: Survival by Gender
- Bar chart: Survival by Passenger Class
- Histogram: Age Distribution of Passengers

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📂 Dataset
- Titanic Dataset (Kaggle – train.csv)

## ✅ Key Learnings
- Handling messy real-world datasets
- Performing Exploratory Data Analysis (EDA)
- Communicating insights through visualizations
